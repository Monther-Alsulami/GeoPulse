## 🌟 مميزات المنصة (Platform Features)

1. **الجيولوجيا البنائية (Structural Geology):**
   - **مدخل للجيولوجيا البنائية (Stress & Strain):** تحليل مفاهيم الإجهاد والانفعال ومحاور الإجهاد الرئيسية ($\sigma_1, \sigma_2, \sigma_3$)، مع مخطط إهليلج الإجهاد (Stress Ellipsoid) التفاعلي.
   - **التشوّه اللدن (Ductile Deformation):** شرح هندسي مفصل لأجزاء الطية (Anticline & Syncline)، المستوى المحوري، والمفصلة، والتورق والتخطط.
   - **التشوّه الهش (Brittle Deformation):** دراسة الفواصل والفوالق وأنواعها (العادية، المعكوسة، المضربية) وفق ميكانيكا أندرسون مع مخططات الحركة النسبية.

2. **الدرع العربي (Arabian Shield):**
   - **النشأة والتطور التكتوني:** توثيق دورة ويلسون وتفكك قارة رودينيا، التحام الأقواس الجزرية المحيطية، وأحزمة الأفيوليت (نطاقات بئر عمق وينبع)، وصدوع نجد المضربية.
   - **نظام ASLLC لتصنيف الصخور:** الشرح المنهجي للتصنيف الليثوديمي الصادر عن هيئة المساحة الجيولوجية السعودية للمجمعات والكتل النارية والمتحولة.

3. **مكتبة الكتب والمقالات وإضافة المراجع (Books & Articles Hub):**
   - مراجع عالمية وسعودية قياسية معتمدة (مثل Fossen, Davis & Reynolds, Twiss & Moores, Johnson & Kattan, Kashgari).
   - زر تفاعلي **(إضافة كتاب أو مرجع)** يتيح رفع صورة غلاف المرجع (مطلوبة) ووضع الرابط المباشر للشراء أو القراءة من الناشر الأصلي، وحفظها محليًا في المتصفح (`localStorage`).
   - شريط بحث فوري مع فلاتر موضوعية لتصنيف المراجع.

4. **سياسة حماية حقوق الملكية الفكرية (Zero-PDF Policy):**
   - احترامًا لحقوق المؤلف والناشرين: **لا يستضيف الموقع أي ملف PDF لأي كتاب أو مقال محليًا**. جميع الروابط تنقل الزائر مباشرة إلى مواقع دور النشر والمنظمات الرسمية (Cambridge, Wiley, SGS, Springer).

5. **دعم كامل للغتين (Arabic & English):**
   - تبديل فوري وكامل لكافة عناصر الصفحة، النصوص، النماذج، والاتجاهات (RTL / LTR).

## 🚀 النشر التلقائي عبر GitHub Pages (Auto-Deployment)

المشروع مهيأ بالكامل للنشر والتحديث التلقائي فور رفع التعديلات على مستودع GitHub:
1. يحتوي المستودع على سير عمل GitHub Actions جاهز في المسار:
   `.github/workflows/deploy.yml`
2. بمجرد عمل `git push` لفرع `main`، يبدأ GitHub تلقائيًا ببناء الموقع ونشره على الرابط الحي:
   `https://<username>.github.io/<repo-name>/`

للمزيد من تفاصيل التفعيل، راجع ملف [DEPLOYMENT.md](file:///z:/Projects/GeoPulse/DEPLOYMENT.md).
